# 沉稳炫酷 · 启动开场风格指南

> 来源：API Watch 桌面端启动动画（2026-09）  
> 气质关键词：**克制、暗调、银白细线、字距呼吸、向产品形态溶解**  
> 目标：炫酷但不吵；有仪式感，不闪不跳。

---

## 1. 风格定位

| 要 | 不要 |
|---|---|
| 深炭黑半透明帷幕 + 轻模糊 | 纯黑死板遮罩 / 霓虹紫粉渐变 |
| 1px 银白竖线、细圆环 | 粗描边、发光拖尾、粒子爆发 |
| 字距从疏收到适中（blur → 清晰） | 弹跳、旋转、闪烁、进度条感 |
| 退场时整体向产品锚点漂移并虚化 | 硬切 / 突然消失 |
| 总时长约 3s，节奏偏慢 | 碎响特效、循环呼吸灯 |

一句话：**像高端设备冷启动，而不是游戏开屏。**

---

## 2. 色彩与材质

```css
/* 帷幕 */
radial-gradient(ellipse 65% 50% at 50% 46%, rgba(22, 28, 40, 0.75), transparent 68%),
rgba(4, 5, 8, 0.78);
backdrop-filter: blur(20px) saturate(1.05);

/* 细线 / 环 */
rgba(210, 220, 235, 0.28 ~ 0.55)

/* 主品牌字 */
rgba(244, 245, 247, 0.94)

/* 副文案 */
rgba(210, 218, 230, 0.40)

/* 字母标（如 AW） */
rgba(236, 240, 245, 0.90)
```

- 主色是**冷灰银**，不是品牌色大块铺陈。  
- 模糊只用于帷幕与退场，主体图形本身几乎不发光。  
- 字体建议：`Outfit`（或同级几何无衬线），字重 500–650。

---

## 3. 结构骨架（HTML）

自上而下中轴对齐，四层叙事：

```
splash
├── splash-veil          ← 全屏暗纱
└── splash-core
    ├── splash-line      ← 竖线（先出现）
    ├── splash-mark
    │   ├── splash-ring  ← 细圆环
    │   └── splash-glyph ← 短字母标（AW）
    └── splash-copy
        ├── splash-brand ← 产品名（宽字距）
        └── splash-tag   ← 一句功能诗
```

启动时：`body.booting` 隐藏正式 UI。  
结束时：加 `splash.is-leaving` → 卸掉 `booting` → `splash.remove()`。

---

## 4. 时间轴（可直接复用）

缓动主曲线：`cubic-bezier(0.22, 1, 0.36, 1)`（入）  
退场曲线：`cubic-bezier(0.4, 0, 0.2, 1)`（出）

| 时刻 | 元素 | 动作 |
|------|------|------|
| 0.00s | veil | 淡入 ~0.75s |
| 0.12s | core | 整体上移淡入 |
| 0.20s | line | 高度 0 → 52px（1s） |
| 0.35s | ring | scale 0.72 → 1 + 淡入 |
| 0.50s | glyph | 上移淡入 |
| 0.55s | brand | blur(6)→0，字距 0.42em → 0.32em |
| 0.95s | tag | 上移淡入 |
| **2.10s** | — | JS 加 `is-leaving` |
| 2.10–2.96s | veil/core | 帷幕消、主体向右漂移+缩小+blur |
| **2.96s** | — | 移除 splash，正式 UI `dockArrive` |

JS 节拍参考：

```js
const holdMs = 2100;   // 构图停留
const leaveMs = 860;   // 退场动画时长后再销毁
```

总感知时长 ≈ **3 秒**。改品牌名时优先动文案，少动节拍。

## 5. 关键动作配方

复用时按这个顺序编排即可：

1. **竖线生长** — `height: 0 → Npx`，两端透明渐变，像「校准轴」。  
2. **圆环落定** — 极细 `1px` border，轻微 scale，不转。  
3. **字母标** — 短、大写、轻字距。  
4. **品牌字距呼吸** — 初始偏疏 + `filter: blur(6px)`，收到可读字距并去模糊。  
5. **副标题** — 更淡、更疏、更小，最后出现。  
6. **退场溶解** — `translate(向产品所在方向) + scale(0.92) + blur(5)`，同时帷幕淡出；正式 UI 用 `opacity + 轻 blur` 接入。

退场方向应对齐产品落点（本项目侧栏在右 → `translate(36vw, 0)`；若落点在左则取负）。

---

## 6. 文案语气

- 品牌名：英文或中英混排、少字。  
- 副句：`名词 · 状态`，例如「余额监视 · 贴边静候」。  
- 避免感叹号、营销口号、Emoji。

---

## 7. 复用清单（拷到新项目）

1. 复制 HTML 骨架，替换 `glyph / brand / tag`。  
2. 复制 `styles.css` 中 `Startup splash` 整段（含 `@keyframes`）。  
3. 复制 `playSplash()` 与 `body.booting` 开关逻辑。  
4. 按产品落点改 `splashCoreOut` 的 `translate` 方向。  
5. 正式 UI 用 `body:not(.booting)` 触发入场动画。

本仓库落点：

- 结构：`renderer/index.html`（`.splash`）  
- 样式：`renderer/styles.css`（`/* ========== Startup splash ========== */`）  
- 节拍：`renderer/app.js`（`playSplash`）

## 8. 质量自检

- [ ] 有没有「闪一下」的高亮或循环 pulse？→ 去掉  
- [ ] 颜色是否只剩冷灰银 + 暗纱？→ 是  
- [ ] 退场是否像「收进产品」而不是「关窗」？→ 是  
- [ ] 静音也能看懂叙事（线 → 标 → 名 → 走）？→ 是  
- [ ] 3 秒内结束，不挡第二次操作？→ 是
